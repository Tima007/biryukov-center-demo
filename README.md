# Центр доктора Бирюкова — концепт сайта

Адаптивный статический макет на русском языке для обсуждения с владельцем.

Концепт для обсуждения. Имена и материалы в примере условные.

Название и адрес: Центр красоты и здоровья доктора Бирюкова, Краснодар, Севастопольская улица, 5.

Иллюстрации абстрактные. Персонажи условные; квалификации, медицинские услуги, отзывы и результаты лечения не заявлены. Кнопка записи открывает пояснение, заявки не отправляются и данные не собираются.

## Открытие

Откройте index.html в браузере. Для GitHub Pages используйте ветку main и папку / (root), режим Deploy from a branch. Сборка не нужна.

Шрифты загружаются с Google Fonts; при недоступности используются системные шрифты.
